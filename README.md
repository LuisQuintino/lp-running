---

## Justificativa do PAC
Este projeto foi desenvolvido como parte do PAC (Projeto de Aprendizagem Colaborativa Extensionista) e visa beneficiar a LP Running, uma assessoria de corrida que enfrenta dificuldades em gerenciar e acompanhar a performance de seus atletas de forma eficiente.  

Por meio deste aplicativo, buscamos oferecer uma solução que centralize dados de treinos, melhore o acompanhamento dos atletas pelos coaches e proporcione uma experiência otimizada para gestão esportiva, contribuindo para o crescimento e a qualidade dos serviços oferecidos pela assessoria.  

---

## Descrição do App  
O aplicativo de assessoria de corrida foi projetado para:  
- Salvar dados de treinos dos atletas.  
- Permitir que coaches filtrem e visualizem os melhores treinos.  
- Acompanhar a performance e a evolução dos alunos ao longo do tempo.  
- Facilitar o registro e gerenciamento de treinos e atletas.  

O app conta com telas intuitivas para gestão de treinos, visualização de resultados e cadastro de informações personalizadas.

## Requisitos para Preparar o Ambiente de Desenvolvimento  
1. **Pré-requisitos**  
   - Flutter
   - Dart
   - Editor de código: Visual Studio Code ou Android Studio.  
   - Android SDK e/ou iOS SDK configurados para emulação.  

2. **Passos para Configuração**  
   - Clone o repositório:
     git clone https://github.com/usuario/repositorio.git
     cd repositorio

   - Instale as dependências:  
     flutter pub get

   - Execute no emulador ou dispositivo:  
     flutter run
